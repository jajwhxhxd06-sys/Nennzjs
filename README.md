# SWILL · Meta Extractor

Извлекает EXIF, IPTC, XMP из фотографий **прямо в браузере**.  
Никаких серверов, всё локально.

## Использование
1. Открыть `index.html` или залить на GitHub Pages.
2. Перетащить фото или кликнуть для выбора.
3. Получить все метаданные в читаемом виде.
4. Скопировать или скачать как JSON.

## Технологии
- Чистый JS
- Библиотека [exifr](https://github.com/MikeKovarik/exifr)
- Адаптивный дизайн

## Деплой на GitHub Pages
1. Создать репозиторий.
2. Загрузить эти файлы.
3. В настройках репозитория включить Pages (ветка main, папка /).
4. Готово — сайт доступен по `username.github.io/repo-name`
